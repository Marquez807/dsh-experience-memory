# 已经问过的方向，和它们的答案

这份文件是给**下一个会话**看的：这里每一条，都是有人真的提过、真的查过、并且**已经有答案**的方向。重提之前先读这里。

**为什么需要它**：这个插件自己的结论，过去没有被它自己记住过一次。2026-10-15，一个会话提议"把重复的经验合并成一条更好的"，而 `docs/CLAIMS.json` 里 `t2.handoff-merge` 早就写着：三条合一 vs 三条分开实测平局、未达门槛、所以**没有采纳自动合并**。一个做记忆的项目，靠人肉记住自己的结论——这条就是那个教训的产物。

**规则**：标 `作废` 的条目必须带一个**仓库内真实存在**的凭证文件（`tests/docs.test.ts` 会逐个核对），所以删掉凭证就等于删掉结论——这是故意的。

## 怎么用

- **提一个新方向之前**：先搜这里。命中 `作废` 就先看凭证，确认那条路是不是真被堵死了——如果只是因为当年的判据不对，那要说清新判据强在哪，而不是假装没查过。
- **做出一个新结论之后**：加一行。作废的必须带仓库内凭证，否则下一个会话无法复核。
- 这份文件**只放"问过的方向"**：功能说明在 `README.md` 的配置表，改动历史在 `CHANGELOG.md`，测评口径在 `docs/GROWTH.md` 与 `docs/DELIVERY-GAPS.md`。
