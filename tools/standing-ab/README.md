# `standing` A/B —— 标了常驻的规矩，模型真的照做吗

验证**常驻层**（`memory_remember` 的 `standing: true`）在真模型上是否既送达、又被照做。
这是 0.4.0 那一层唯一还能被证伪的地方：单元测试只能证明"上下文里会出现它"。

## 场景

临时工作区里只有一份 `TASK.md`：「写个 `hello.py`，运行打印 hello」。
约定是「本工作区新建的每个文件，第一行必须写 `# owner-tag: zx9`」——
**这条约定不写在任何文件里**，只存在于库里那一条记录里。

判定**只看产物**（`hello.py` 的第一行），不看模型自己说了什么。

| 臂 | 库里那一条记录的状态 |
|---|---|
| `absent` | 库是空的 |
| `control` | 同一条记录在库里，**不标常驻** |
| `standing` | 同一条记录，**标常驻** |
| `sham` | 标常驻，但讲的是**另一件不相干的事**（日志放 `var/log/`） |

## 怎么跑

```powershell
# 隔离 home 建在 %TEMP%\abx，每次重建空库、只播一条记录；真库与本工作区都不碰
powershell -ExecutionPolicy Bypass -File tools\standing-ab\run-ab.ps1 -Trials 6 -Arms absent,control,standing
node tools\standing-ab\stats.mjs        # 汇总 + Fisher 精确检验（双侧）
```

`run-ab.ps1` 用 DSH 自带的 headless 入口跑真回合：

```
node <app>\node_modules\@deepseek-ai\dsh\lib\bin.js --profile sab "Follow the instructions in TASK.md."
```

`seed.mjs <库> <工作区> <臂>` 直接调插件自己的 `upsert` 播一条记录（绕过定级，因为离线没有用户消息可引）。

## 结果（2026-09-25，模型 `deepseek-official/deepseek-flash`，每格 6–18 秒）

| 臂 | 带标记 |
|---|---|
| `absent` | 0 / 6 |
| `control` | 0 / 6 |
| `standing` | **6 / 6** |
| `sham` | 0 / 6 |

**24 个真回合：标常驻 6/6，其余各臂合计 0/18，Fisher 双侧 p = 0.000007。**
原始行在 `results.jsonl`（一行一格，含 `started` / `timeout` / 首行内容），`node stats.mjs` 可重算。

读法：环境本身不会产生这个标记（`absent`、`sham` 都是 0——不是"模型每次都会加文件头"，也不是"随便给条常驻记录"就行）；
只有那一行文字真的到了模型眼前，它才会照做；而只有标了常驻，那一行才会每一轮都到。

**一条不作为凭证的观察**：`control` 臂在早先一轮里出现过 2/4（那一轮的原始行已被本轮覆盖，
所以这里的 0/6 才是凭证）。它说明不标常驻时**偶尔**也能到——查询层撞上共同词时会顺手带上它。
这恰好是常驻层的意义：把"碰运气"变成"保证"。

## 两条教训（都是踩出来的）

1. **目录名不许与记录共有词**。第一版实验根目录叫 `dsh-standing`，而记录里有 `dsh` 这个词——
   **路径本身就是检索查询的一部分**，于是"不标常驻"的对照组 4/4 全中，看起来像"标不标都一样"。
   改成 `abx` + 标记词换成 `zx9` 之后才看清。任何"有/无"对照实验都要检查：两臂之间除了那一个变量，
   还有没有**任何字符串**可能被检索到（路径、目录名、文件名、任务正文）。
2. **"智能体没起来"必须与"模型做错了"分开**：每一格都记 `started`（跑完有没有新会话落盘）与 `timeout`，
   汇总时只统计 `started && !timeout` 的格子。配额/网络故障应当记成占位行、可续跑，不能计入分子分母。

## 已知不足

- 只测了**一条**规矩、**一个**任务；判断类、要多轮才见效的规矩没测。
- 会话日志里读不到"这一轮注入了什么"（压缩存储，且似乎不记录插件注入的那段），所以"送达"是靠行为对照推出来的，
  不是直接读出来的。`look.py` 是当时的尝试，留在这里作为记录：它证明了**日志里找不到那行文本**，而不是没送达。
